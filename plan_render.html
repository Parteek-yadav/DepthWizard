Executive Objective: Construct a production-grade, scientifically grounded, zero-placeholder end-to-end pipeline that transforms single-view optical RGB remote sensing imagery into calibrated relative or absolute Digital Surface Models (DSM) and an interactive 3D WebGL flythrough environment with structural and topographical height analysis tools.

1. Dual Ingestion Pipelines

Mode 1: Non-Georeferenced (PNG / JPG)
  • Input: Aerial drone / satellite RGB image snapshots.
  • Inference: Zero-shot Depth Anything V2 monocular backbone.
  • Output: Relative Digital Surface Model (rDSM), normalized elevation [0, 1].
  • 3D Engine: Height-exaggerated terrain mesh textured with source RGB.
  • Disclaimer: UI transparently marks heights as relative units.
Mode 2: Georeferenced (GeoTIFF / Raster)
  • Input: Satellite imagery with CRS, bounds & GSD transform.
  • Alignment: Matched reference DEM (SRTM/COP30) or user GCPs.
  • Calibration: Robust Huber scale-offset regression (Z = s · D_rel + t).
  • Output: Absolute Metric DSM (in meters) + GeoTIFF export.
  • Quality: Explicit MAE, RMSE, Pearson r, and R² validation metrics.

2. Depth-to-Elevation Mathematical Calibration

Rather than pseudo-normalizing depth, DepthWizard derives absolute physical elevation via robust M-estimation (Huber Regression) against spatial control reference points:

Metric Elevation: Z_pred(x, y) = s · D_rel(x, y) + t
Objective: min_{s, t} ∑ ρ_δ(Z_ref(x_i, y_i) - (s · D_rel(x_i, y_i) + t))
Metrics: RMSE = √( 1/N ∑ (Z_pred - Z_ref)² ), MAE = 1/N ∑ |Z_pred - Z_ref|, R² = 1 - (SS_res / SS_tot)

4. Interactive 3D Terrain Engine & Geospatial Tools

3D Terrain Flythrough Features
  • Dual Camera Modes: First-Person Drone flight (WASD + Mouse look) & Orbit mode.
  • Real-time Exaggeration: Dynamic vertical scaling slider (0.1x – 5.0x).
  • Shader Materials: True Optical RGB texture, wireframe overlay, and scientific colormaps (Turbo, Viridis, Terrain).
  • Lighting Controls: Solar azimuth and elevation controls for dynamic micro-relief shadows.
Geospatial Analysis Suite
  • Point Query: Click-to-inspect precise (Lat, Lon, Elevation Z).
  • Structural Height Measurement: 2-point 3D measurement for building/cliff heights (ΔZ).
  • Slope Computation: Direct grade percentage and angle (θ°) between points.
  • Elevation Cross-Section: Dynamic line-profile elevation graph across ridges.
  • Distribution Histogram: Hypsometric curve & terrain statistics.

6. 3-Minute SIH Jury Presentation Workflow

  1. Step 1 (Ingestion): Select bundled GeoTIFF sample. System reads spatial metadata (CRS: EPSG:32643, GSD: 0.5m, Dimensions: 1024 x 1024).
  2. Step 2 (Depth Inference): Zero-shot Depth Anything V2 generates relative depth map with dense micro-relief preservation.
  3. Step 3 (DEM / GCP Calibration): Spatial aligner pairs relative depth with reference SRTM elevation, displaying Huber calibration fit (R² = 0.94, RMSE: 2.8m).
  4. Step 4 (3D Mesh & Texture Mapping): Triangulated terrain mesh generated with optical RGB texture mapped 1:1 onto vertices.
  5. Step 5 (Interactive Flythrough): Pilot the camera in first-person drone mode across mountain ridges and structures.
  6. Step 6 (Spatial Analysis & Export): Measure building height (ΔZ = 42.5m), draw a cross-section profile, and export the calibrated GeoTIFF DSM.
